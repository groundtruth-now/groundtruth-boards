# GROUNDTRUTH daily boards

Every pump.fun day, counted. On-chain, every row, with N.

- **GRADUATION DAY**: coins that migrated on-chain that UTC day, and how many are already under 100 SOL.
- **BUSIEST HANDS**: the wallets that signed the most pump.fun creates that day.
- **THE TOLL**: pump.fun fees traders paid on that day's graduates that are now dead.

Each day: `data/<YYYY-MM-DD>/boards.json` (every row, full mints and wallets), `METHOD.txt` (the rules, written before the numbers), and the posts.
Every coin and every wallet has a card: `https://groundtruths.xyz/autopsy?ca=<address>`.
